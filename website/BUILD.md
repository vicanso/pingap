# Building the documentation site

Bilingual static documentation for Pingap, deployed to GitHub Pages.

## Languages

| Path | Language | Source of truth |
| --- | --- | --- |
| `/` | redirect → `/en/` | `website/index.html` (`?lang=zh` → Chinese) |
| `/en/` | English (default) | `pingap-*/README.md`, `pingap-plugin/docs/*`, `docs/`, `examples/` |
| `/zh/` | 中文 | `docs/zh/**` (maintained translations) |

## Build

```bash
./scripts/build-website.sh
python3 -m http.server -d website 8080
# http://127.0.0.1:8080/      language picker
# http://127.0.0.1:8080/en/   English
# http://127.0.0.1:8080/zh/   中文
```

## Updating Chinese docs

Edit files under `docs/zh/` (not under `website/zh/` — that tree is generated).

When you add a new English plugin doc, also add `docs/zh/plugins/<name>.md` and
list it in the Chinese sidebar generated by `scripts/build-website.sh`.

## Hand-maintained files

| Path | Role |
| --- | --- |
| `index.html` | language picker |
| `en/index.html`, `zh/index.html` | docsify shells |
| `assets/` | logo, CSS, shared docsify bootstrap |
| `.nojekyll` | disable Jekyll on GitHub Pages |
| `BUILD.md` | this file |

## CI

`.github/workflows/pages.yml` runs the build script and deploys the whole
`website/` directory via GitHub Pages (Actions source).
